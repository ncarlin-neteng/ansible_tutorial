	- We can generate ssh keys with the following commands:
		○ ssh-keygen -t ed25519

	- We will get a private and public key.
		○ Public key has .pub at the end.

	- Should save in $HOME/.ssh/

	- To copy a key to another se rver, we can run the following command
		○ ssh-copy-id -i ~/.ssh/id_ed25519.pub 192.168.158.128
